# Research: no-code платформа для обучения роботов и других агентов с помощью RL

Рабочее название проекта в этих материалах: **«платформа»** (бренд пока не выбран).

**Идея основателя:** no-code платформа, где люди без экспертизы в ML могут обучать своих роботов,
а также других агентов (не только роботов) с помощью обучения с подкреплением (RL) и смежных методов.

Дата начала исследования: 2026-10-27.

## Правила для всех агентов (обязательные)

1. **Перед началом работы прочитай этот README и все уже существующие файлы в `research/`.**
   Не дублируй чужие темы — ссылайся на них: `(см. 02-rl-tech-state-of-art.md, раздел «Sim2Real»)`.
2. **Каждый файл начинается с подписи:**
   ```
   > Автор: агент «<роль>» · Дата: <YYYY-MM-DD> · Прочитанные файлы research/: <список или «нет»>
   ```
3. **Каждое фактическое утверждение (цифры, даты, раунды, цены, характеристики) сопровождается ссылкой** вида `[n]`,
   а в конце файла есть раздел `## Источники` со списком:
   `[n] Название — издатель/автор — URL — (дата обращения 2026-10-27)`.
   Цитировать только то, что реально найдено в источнике. Нельзя придумывать URL.
4. **Разделяй факт, оценку и мнение.** Оценки помечай `(оценка)`, собственные выводы — `(вывод)`.
   Если источники противоречат друг другу — укажи оба и это противоречие.
5. **Уровень уверенности:** для ключевых цифр ставь `[уверенность: высокая/средняя/низкая]`.
6. **Свежесть:** сейчас октябрь 2026. Ищи данные 2025–2026 гг.; устаревшие данные помечай годом.
7. **Язык:** текст на русском, названия компаний/продуктов/статей — в оригинале.
8. **Каждый файл заканчивается разделом** `## Выводы для платформы` — 5–10 конкретных пунктов,
   что это значит для нашего продукта/бизнеса, перед разделом `## Источники`.
9. Честность важнее оптимизма: явно пиши о слабых местах идеи, конкурентных угрозах и неизвестных.
